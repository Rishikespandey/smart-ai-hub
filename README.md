# 🚀 SmartAI Hub – Full-Stack AI SaaS Platform

SmartAI Hub is a **production-ready AI SaaS platform** that combines multiple AI-powered tools into a single modern web application. It allows users to interact with AI for chat, image generation, resume analysis, and content summarization.

---

## 🌐 Live Demo
https://smart-ai-hub-phi.vercel.app/

## ✨ Features

* 🤖 AI Chat

  * Smart conversational AI
  * Markdown support
  * Real-time responses

* 🎨 Image Generator

  * Generate images using text prompts
  * Fast AI-based rendering

* 📄 Resume Analyzer

  * AI-powered resume feedback
  * Suggestions for improvement

* 📝 Notes Summarizer

  * Convert long text into short summaries
  * Quick insights extraction

---

## 💡 Unique Highlights

* ✅ Credit-based system (20 free credits for new users)
* ✅ Real-time credit tracking & deduction
* ✅ History tracking (Chat, Notes, Images)
* ✅ Fully responsive (Mobile + Tablet + Desktop)
* ✅ Clean UI with smooth animations

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

git clone https://github.com/your-username/smartai-hub.git
cd smartai-hub

---

### 2️⃣ Setup Backend

cd backend
npm install

Create a `.env` file inside backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_key
HUGGINGFACE_API_KEY=your_hf_key

Run backend:

npm start

---

### 3️⃣ Setup Frontend

cd frontend
npm install
npm run dev

---

## 🔐 How It Works

1. User signs up / logs in
2. Gets 20 free credits
3. Uses AI tools (chat, image, notes, resume)
4. Credits are deducted per usage
5. History is stored and displayed
